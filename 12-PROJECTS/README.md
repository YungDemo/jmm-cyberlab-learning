# 12-PROJECTS

This section is for applied, evidence-based work.

## Types of projects
- phishing forensics
- SOC lab exercises
- detection engineering projects
- future projects

## Purpose
Projects show practical understanding beyond theory. They are also strong evidence for job applications, interviews, and portfolio reviews.

## Example structure
- project summary
- objective and scope
- steps taken
- tools used
- artifacts produced
- findings and lessons learned

## Good project habit
Each project should end with a short write-up and a clear link to the knowledge you gained.
