# 02-SOC

This folder covers Security Operations Center functions and the operational side of security.

## Core topics
- SOC fundamentals
- SIEM
- EDR
- IDS/IPS
- incident response
- threat intelligence
- MITRE ATT&CK
- SOC metrics

## Focus areas
- alert triage and prioritization
- incident investigation steps
- evidence collection
- escalation and communication
- response coordination
- threat hunting and detection improvements

## Best practices
- document investigation steps in a structured format
- write down alert source, severity, scope, and impact
- link findings to MITRE ATT&CK techniques where possible
- keep runbooks and notes reusable

## Recommended outputs
- SOC playbook notes
- investigation templates
- alert walkthroughs
- detection tuning notes
