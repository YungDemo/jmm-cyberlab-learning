# SOC Fundamentals

This folder is dedicated to the concepts and operating model of a Security Operations Center.

## Focus Areas
- alert triage
- monitoring and coverage
- escalation paths
- incident response lifecycle
- threat hunting
- case management
- SOC metrics and reporting

## Learning Goals
- understand how a SOC functions operationally
- identify the difference between monitoring, detection, and response
- learn how analysts investigate alerts using evidence and telemetry

## Suggested Outputs
- SOC process notes
- real-world alert walkthroughs
- step-by-step investigation templates
- threat intelligence summaries
