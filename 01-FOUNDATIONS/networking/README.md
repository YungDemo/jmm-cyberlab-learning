# Networking

This folder is for networking concepts and practical study.

## Core Topics
- IP addressing and subnetting
- OSI and TCP/IP models
- routing and switching
- VLANs and segmentation
- DNS, DHCP, NAT
- firewalls and network access controls
- protocols and packet analysis

## Suggested Activities
- build a home lab with multiple virtual networks
- document common protocols and ports
- practice Wireshark and packet capture review
- create a network diagram for your lab
