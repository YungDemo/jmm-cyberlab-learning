# 01-FOUNDATIONS

This section is the base layer for the entire repository.

## Core topics
- networking
- Linux administration
- Windows administration
- cybersecurity fundamentals
- cryptography

## Why this matters
Security work depends on a strong understanding of how systems and networks behave. If you can reason about OS behavior, network flow, and cryptographic protections, you will be much better at detection, investigation, and defense.

## Good study activities
- create a basic network diagram
- practice Linux commands and file permissions
- review Windows services, logs, and security settings
- study common attack surfaces and mitigations
- document encryption and hashing concepts

## Output ideas
- cheat sheets
- command reference notes
- lab write-ups
- small network diagrams
- glossary of key terms
