# 08-CLOUD-SECURITY

This folder covers cloud security and scalable modern environments.

## Topics
- Azure
- AWS
- IAM
- cloud monitoring

## Core focus areas
- IAM best practices
- privilege boundaries
- cloud logging and monitoring
- posture management
- identity and access controls
- secure architecture patterns

## Considerations
Cloud environments require a different mental model than traditional on-premises systems. Understand shared responsibility, access models, and logging sources before building complex workloads.
