# 05-DETECTION-ENGINEERING

This section is for defenders who write and tune detections.

## Topics
- KQL
- Sigma
- YARA
- Snort
- detection rules

## Goals
- understand detection logic
- identify noisy vs meaningful alerts
- write rules that reduce false positives
- map detections to real attacker behavior

## Good practice
- always document rule intent
- include attack scenario and expected telemetry
- write assumptions and tuning notes
- preserve versions and refinements as you improve rules

## Example outputs
- Sigma rules
- KQL hunting queries
- correlation logic notes
- threat scenario checklists
