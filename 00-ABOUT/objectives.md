# Objectives

## Primary Objectives
- Build a broad understanding of information security and cyber defense
- Gain hands-on experience across multiple security domains
- Practice detection, investigation, triage, and response workflows
- Develop a portfolio of projects, labs, and technical write-ups
- Prepare for certifications and practical, role-based work

## Secondary Objectives
- Learn operational thinking used in SOC environments
- Improve technical documentation and incident reporting skills
- Understand attacker tactics and defensive countermeasures
- Build confidence in lab-driven learning and self-assessment
