# 00-ABOUT

This section is your learning map and personal baseline.

## Purpose
Use this folder to define:
- your goal in cybersecurity
- your learning journey timeline
- the topics you want to master
- the skills you have already built

## Recommended documents
- `learning-journey.md` — your overall progression path
- `objectives.md` — target outcomes and learning goals
- `cybersecurity-roadmap.md` — recommended order of learning
- `skills-matrix.md` — track confidence and mastery by domain

## Suggested workflow
1. Read the roadmap and define your target role.
2. Set 30/60/90 day goals.
3. Review your skill matrix every week.
4. Update notes after each lab or project.
