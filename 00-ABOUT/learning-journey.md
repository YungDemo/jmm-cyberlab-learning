# Learning Journey

This repository is designed as a structured, step-by-step path for a cybersecurity learner who wants to move from fundamentals into specialized operational roles.

## Stage 1: Foundations
Learn the technical basics needed to reason about systems, networks, and security controls.

## Stage 2: Security Operations
Understand how SOC teams monitor, investigate, and respond to malicious activity.

## Stage 3: Microsoft Security and KQL
Develop practical skills in Microsoft Sentinel, Defender XDR, and investigative workflows.

## Stage 4: DFIR and Threat Hunting
Learn how to investigate evidence, artifacts, and malicious activity across endpoints and systems.

## Stage 5: Detection Engineering and Pentesting
Practice writing detections, rules, and attack simulation scenarios.

## Stage 6: Home Lab and Hands-On Practice
Build lab environments for realistic testing and repeatable skill development.

## Stage 7: Career Evidence
Document certifications, write-ups, projects, and accomplishments to strengthen career readiness.
