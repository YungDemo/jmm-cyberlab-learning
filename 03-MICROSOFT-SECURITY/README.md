# 03-MICROSOFT-SECURITY

This section focuses on Microsoft security tools and workflows.

## Topics
- SC-200
- Microsoft Sentinel
- Defender XDR
- Defender for Endpoint
- Defender for Identity
- KQL
- incident investigation

## Learning objectives
- understand Microsoft security architecture
- learn how to analyze alerts in Defender and Sentinel
- build confidence with KQL for investigations
- connect telemetry, incidents, and remediation actions

## Good exercises
- build a hunting query
- review portal dashboards and alert mappings
- create notes on incident triage flow
- compare detections to real attacker techniques

## Suggested artifacts
- KQL query library
- incident notes
- enrichment and investigation checklists
- screenshots of real detection workflows
